# Selective Trajectory Reconstruction with ISMD Preservation

This repository contains a static academic project page for the trajectory reconstruction study.

## Project page

The GitHub Pages site is designed to be served from the `docs/` folder.

After uploading this folder to GitHub, enable:

```text
Settings -> Pages -> Deploy from a branch -> main -> /docs
```

The project page will then be available at:

```text
https://<github-username>.github.io/<repository-name>/
```

## Contents

- `docs/index.html`: project homepage
- `docs/static/images/`: static figures used on the page
- `docs/static/videos/intersection.gif`: dynamic comparison demo
- `code/make_intersection_gif.py`: script used to generate the dynamic demo
- `Multi-model_trajectory_reconstruction_results.xlsx`: performance summary table source
